# 概览

本案系××市公安局××分局侦查终结移送审查起诉的周立新涉嫌诈骗案（×公（经）诉字〔2025〕第0417号）。起诉意见书认定：周立新虚构"鑫达生态农业项目"已获政府补贴、保本且年收益12%的事实，骗取被害人陈美华信任，于2025年3月12日、3月20日分两次收取陈美华转账共计180,000元，后将款项用于归还个人欠款、汽车维修、日常消费等，未投入任何农业项目，涉嫌触犯《中华人民共和国刑法》第二百六十六条（法律依据待律师核实）。案件目前处于移送审查起诉阶段。

**各方主要说法**
- 陈美华称：经赵刚介绍于2025年3月10日认识周立新，周立新称项目保本、年收益12%，遂分两次转账18万元；周立新未还钱，5月初起不接电话。第二次询问时补充称2025年5月6日收到周立新转账50,000元，但认为该款项系周立新暂存其处、非还款，故仍主张欠款18万元。
- 周立新称：系公司资金周转困难向陈美华借款18万元，仅称项目前景好，未说过保本；2025年5月6日转账50,000元系归还部分本金和利息。第三次讯问时改口称"可能说过保本这类话"，并承认50,000元系还款。
- 赵刚称：2025年3月10日介绍双方认识，周立新称"项目稳赚不赔"，"有没有说保本我记不太清了"；事后周立新给其2000元感谢费。
- 刘某某称：2024年11月借给周立新6万元，2025年3月13日收到还款60,000元，不知资金来源。
- 孙丽称：公司2025年上半年无经营收入，账上无租地、大棚支出，陈美华18万元转入周立新个人账户未进公司账，公司未收到或申请过补贴。

**要点**
- 是否承诺"保本"：陈美华、微信记录与周立新第三次讯问一致；周立新前两次讯问否认。
- 50,000元性质：陈美华称系暂存非还款；周立新第三次讯问称系还款；微信记录显示周立新称"先转你5万，你先放着"。
- 款项去向：起诉意见书认定用于个人用途；银行明细显示2025年3月13日转刘某某60,000元、3月21日消费12,800元。
- 政府补贴：周立新称镇干部口头承诺；镇政府情况说明称未收到申请、未发放或承诺补贴。
- 项目真实性：孙丽称公司无相关支出；镇政府称未见大棚项目。
