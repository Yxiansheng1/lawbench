# 争议焦点

### 1. 款项性质：投资款还是借款
- 起诉意见书认定：周立新以"入股"名义骗取陈美华投资款，未投入任何农业项目〔起诉意见书 第2页〕
- 陈美华称：周立新说"是入股，年底一起结算"，没有写借条、没签合同〔被害人陈美华询问笔录（第一次） 第4页〕
- 周立新称：是借款，"是她借给我的，我当时公司资金周转困难，跟她说借半年，给她利息。她一共借给我18万"，"没有写借条，我们口头说的"〔犯罪嫌疑人周立新讯问笔录（第一次） 第3页、犯罪嫌疑人周立新讯问笔录（第二次） 第4页〕
- 孙丽称：周立新提过陈美华投了18万进来，"是投资款"，但钱转到周立新个人卡上，未进公司账户〔证人孙丽询问笔录 第5段〕
- **需要律师关注**：各方对款项性质说法不一，无书面协议；需核实是否存在借条、合同或其他书面凭证
