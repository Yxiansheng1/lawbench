## 6. 自检与遗留、偏离、模糊条款

- **`CI=true` 必需**：DSH 根 `postinstall` 跑 `scripts/install-lefthook.mjs`，在我们的 git worktree 布局下报"cannot enable extensions.worktreeConfig while core.worktree is in the common config"并失败；`pnpm run` 每次先做依赖检查会重跑 install，也跟着失败。该脚本在 `CI=true` 时直接返回，只跳过 git 钩子安装，不影响构建与运行。未改 DSH 代码。
- **Electron 下载**：`apps\desktop` 依赖 electron 44.0.0；经本机代理从 GitHub 下载 0 字节停滞。经 owner 当场批准（2026-09-29）改用 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`，下载完成。仅开发工具链，不涉及产品外连。
- **pnpm 不在 PATH**：用 `corepack pnpm@11.7.0`（与 DSH `packageManager` 一致）。`corepack enable` 因 `D:\node` 目录无写权限报 EPERM，不影响 `corepack pnpm@...` 直接调用。
- **测试 3 败**（与我方无关）：
  1. `packages/client/ui-deliverables/tests/present-open.host.spec.ts` "refuses final symlinks"：Windows 非管理员无创建符号链接权限（`EPERM: symlink`）。
  2. `packages/client/connection/tests/binary-rpc.host.spec.ts` "preserves gzip / none configuration through the HTTP bridge"：约 10 秒超时，并行负载下的计时问题。
- 事实索引文件按执行令未改，两行内容见第 5 节。
