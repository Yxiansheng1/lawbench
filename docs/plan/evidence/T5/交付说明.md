## 3. 导入规则（Spec 5.1）

**复制方式**：只复制，不移动。

**目标位置**
- 默认：有 `02案件材料` 就放进去，没有就放案件根目录。
- 显式指定的目标要过闸门，不能是 `工作区`、`成果`、以 `.` 开头、带 `..` 或盘符的路径。
- 目标文件夹不存在时，由闸门逐级新建。

**文件夹**：整体复制，保留内部结构；夹内的链接、快捷方式逐项跳过，其余照常复制。

**跳过，并写明原因**
- 源在云同步目录（和 SEC-14 用同一套检测）；
- `.lnk`、`.url` 快捷方式，以及链接、junction；
- 无法读取；
- 超过 300MB；
- 目标已有同名文件且 sha256 一致。

**同名不同内容**：改名为 `原名(2)`、`原名(3)`……，从不覆盖。

**已在案件内的文件**：不复制，直接扫描。例外是 `工作区\` 下的文件（粘贴的截图、委托材料下载），复制到目标后删掉原来的临时文件。

**ZIP（`unzip=true`）**
- 先检查：条目越界（`..`、以 `/` 开头、带盘符）、含链接条目、超过 500 个文件，任一条命中就整个 ZIP 跳过，原因写"无法读取"。
- 解压到 `工作区\临时\unzip-xxxx\`，逐个文件按上面的规则复制，结束后删除解压目录。
- 顶层含标准目录名（如 `01委托手续`）时，按原结构放到案件根目录；否则放到目标位置。

## 5. 契约与文档

契约和文档都没改。以下几处 Spec 或 formats 没写死，我按下面的取法实现，请 ORCH 裁决。

1. **尚未识别的页不写 `> 识别所得`。**
   - formats 第 2 节原文：`【第2页】`、`> 识别所得`、`<识别文本……；本页尚未识别时为：（本页需识别）>`。
   - Spec 5.3 原文："识别页在标记下一行写 `> 识别所得`"。
   - 我的取法：页还没识别，就不算"识别所得"，块内只写 `（本页需识别）`。识别完成后，由识别队列（T12）替换成 `> 识别所得` 加识别文本。
2. **Source 行的"文字版 / 识别所得 / 部分识别"按 `is_ocr` 取。**
   - 映射：`none` 对应文字版，`partial` 对应部分识别，`full` 对应识别所得。
   - 所以还没识别的扫描件、图片，Source 行也写"文字版"。
3. **Excel 的 `unit_count` 取工作表个数**，与 Source 行"N个工作表"一致。契约只写了 `unit_count`，没说 cell 单位时数什么。
4. **公式单独存放的位置是我定的。**
   - Spec 5.2 原文："公式单独存一份，律师需要时查看"。
   - 存放位置 `工作区\材料\公式\<原件相对路径>.txt`，每行一条：`工作表!单元格`、制表符、公式。
   - formats 第 1 节的目录树里没有这一项，需要的话请补进 formats。
5. **哪些项不当材料。**
   - Spec 4.1 原文："除 `工作区/`、`成果/` 和以 `.` 开头的项以外"。
   - 我的取法有三点：
     - 以 `.` 开头的项在**任何层级**都跳过，不只根目录；
     - 另外跳过 Office 锁文件（`~$…`、`.~lock.…`）以及 `Thumbs.db`、`desktop.ini`。closed-01 的 README 标了 `~$起诉状.docx`"应被忽略"；
     - 契约里 `material_type` 枚举之外的格式（zip、lnk 等）不进材料清单。
6. **检索索引没更新。** Spec 5.1 第 4 步有"更新检索索引"，这归 T9 全文检索；T5 只写材料文本和 `index.json`。
7. **"识别结果标为过期"没有写到任何文件里。**
   - `/api/materials` 的 `stale_ocr` 按一条规则现算：`case.db` 里有该材料已完成的识别任务，但任务记录的 `material_version` 不等于当前 sha256。
   - 识别页文件怎么处理（删除还是保留），留给 T12。
8. **不安全的 ZIP 整包跳过，原因写"无法读取"。** 契约的跳过原因枚举里没有更贴切的词，比如"压缩包不安全"。
9. **ZIP 内文件的 `from` 字段写成"ZIP 绝对路径 + 包内路径"**，例如 `C:\x\委托材料.zip\01委托手续\合同.pdf`，因为 `from` 必须是绝对路径。
10. **加密检测有盲区。**
    - 加密的 docx、xlsx 用 OLE 容器里的 `EncryptionInfo` 流识别。
    - 旧格式 .doc、.xls 的密码保护不走这个机制，LibreOffice 转换会失败，报"无法转换该文件……"，而不是"文件已加密"。
11. **原件变了、重解析却失败时，删掉旧文本。** 这样不会留下与原件不符的旧文本；状态为 `failed`。
12. **有新增、变化或删除之一，`review_needed` 就为 true。** 与契约样例（新增 1 份时为 true）一致。

  - 真机上遇到挂起再考虑按进程树结束。
- **Excel 的显示值是原始值。**
  - 数字不套单元格格式，例如 80000 不显示成 80,000.00；整数形式的浮点数去掉 `.0`；日期写成 ISO。
  - 这样检索和出处核对都能对上 `cite-cases` 里的原文。
- **"图文混排页可提交识别"的提示归界面（T13）。** 服务端只给出 `pages_mixed`。
- **导入的云同步检测只看拖入的顶层路径。** 顶层是文件夹时，里面的文件视为同样的位置。
