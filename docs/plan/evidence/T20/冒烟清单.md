# Windows 候选包冒烟清单（T20）

每次打出候选包后在本机按此清单走一遍，结果写进 `build.txt` 对应一节。

这份清单由令 1426 第 2 条、令 1556 第 2 条、令 1759 和注记 1924 归并而来。前几版的实际做法见 `build.txt` 第二至第六版各节。

本机没有的条件（干净机、原版 DSH、律所网络）列在末尾"本机核不了"一节，不在本机硬造。

## 装前
1. 预置两个"原版 DSH"的标记目录，记下内容和时间。冒烟后删掉。
   - `%LOCALAPPDATA%\@deepseek-aidsh-desktop-updater\marker.txt`
   - `%APPDATA%\@deepseek-ai\dsh-desktop\marker.txt`

## 安装
2. 静默安装 `lawbench-…-unsigned.exe /S /D=<临时目录>`。记退出码和秒数。
3. 布局都在：
   - `contracts\VERSION`
   - `python\python.exe`、`python312._pth`、`lawbench-python-source.json`
   - `service\lawbench\__main__.py`、`tokenizer.json`
   - LibreOffice
   - pandoc 及其 `COPYING.rtf`、`COPYRIGHT.txt`
   - 两个小工具（`tools\splitter\splitter.exe`、`tools\convert\convert.exe`）
   - `engines`
   - `installer\set-skills-acl.ps1`
   - `skills\manifest.json`
   - `THIRD-PARTY-LICENSES.md`
   - `resources\app.asar`
   - `连越律师工作台.exe`
4. 剔除项（令 1337）：
   - 没有 `resources\runtime\primary-runtime`；
   - 没有 `libreoffice-kit-win32-x64` 引擎（只剩约 1 MB 的 `koffi.node`，按令 1556 留着）。
5. 安装缓存：
   - `%LOCALAPPDATA%\lawbench\installer-cache` 装完不在；
   - 第 1 步的两个标记目录内容、时间都不变。
6. 开始菜单有"连越律师工作台""长截图切分""格式互转"，指向安装目录里的程序；桌面一个快捷方式。
7. 内置解释器：`python\python.exe -I -c "import sys;assert sys.stderr.encoding=='utf-8'"` 通过，版本 3.12.10。

## 启动
8. **端口被占**（令 1556、1759）：
   1. 先用一个小程序占住 `127.0.0.1:18765`，再启动。
   2. 记以下时刻：
      - Host 日志 `service.start_failed {exitCode: 2, port: 18765}` 出现（第六版：拉起 6 次、22 秒）；
      - 首次配置页自己显示"本机服务未能启动：本机 18765 端口被其他程序占用，请关闭占用程序后重试"；
      - 首页不点"重试"也显示同一句。
   3. "每次拉起 ≥4 秒也能到 failed"：本机造不出，由 `dsh-ext\tests\supervisor.spec.ts` 的假时钟用例证明，冒烟记录里写明。
9. 放开端口重启：
   - 服务 running，自检 python / tokenizer / libreoffice / pandoc 都 ok；
   - 首次配置页地址已填好、可填；
   - 填虚构的律师姓名 → 首页，"工具：长截图切分、格式互转"可见。截图遮用户名。
10. **旧版覆盖装新版**（注记 1924）：
    1. 先装上一版候选包（用 sha256 不同的两个构建）并启动一次。
    2. 不卸载，直接装新版。
    3. 启动后确认首页和组件都是新版。可对照：
       - 新版才有的界面（如这一版新加的提示、按钮）；
       - `resources\app.asar` 的修改时间与 sha256 等于新包解出的那份。

       设置"通用"里的版本号目前各版都是 0.1.0，分不出来。
    4. 记两个包的 sha256。
    5. 想法（候定，见交付说明）：给 `lawbench-dsh` 组合包的版本带上构建号，界面某处可看到，覆盖装后一眼能分清新旧。

## 卸载
11. 静默卸载 `Uninstall 连越律师工作台.exe /S`。以下都不在：
    - 安装目录；
    - `%APPDATA%\lawbench-desktop`；
    - `%LOCALAPPDATA%\lawbench\dsh-home`；
    - `installer-cache`；
    - 开始菜单三项、桌面快捷方式。

    以下仍在：
    - 两个标记目录（原版不碰）；
    - `%LOCALAPPDATA%\lawbench` 下的日志等（按设计保留）；
    - `HKCU\Software\Classes\dsh`（按设计不删，见共用点清单第 13 项）。

## 收尾
12. 删掉冒烟写的东西，本机恢复原状：
    - `settings.json`、`cases.json`、`daily-case.json`、`案件根名单.json`；
    - `<用户目录>\连越律师工作台`；
    - 两个标记目录。

## 本机核不了（候用户新机）
- 非静默安装时的 Skill 目录提问、默认安装目录名。
- 与真的原版 DeepSeek Harness 同时开。
- 干净机（没有开发环境、开着 Smart App Control）上的启动。
