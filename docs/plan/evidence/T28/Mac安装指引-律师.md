# 连越律师工作台 · Mac 版安装指引

适用：Apple 芯片的 Mac（M1 及以后），macOS 12 或更新。安装包：`lawbench-0.1.0-mac-arm64.dmg`。

## 一、安装

1. 双击打开 dmg，窗口里有三个程序和一个"应用程序"文件夹快捷方式。
2. 把 **"连越律师工作台"、"长截图切分"、"格式互转" 三个程序一起拖进"应用程序"**。两个小工具要和主程序放在一起，才找得到转换程序。
3. 拖完后，在访达侧栏把 dmg 推出。

## 二、第一次打开

这一版还没有经过苹果公证，第一次打开会被 macOS 拦下，按下面做一次即可：

1. 在"应用程序"里双击"连越律师工作台"，看到"无法打开"的提示，点 **完成**。
2. 打开 **系统设置 → 隐私与安全性**，向下翻，在"安全性"一栏看到"已阻止使用连越律师工作台"，点 **仍要打开**。
3. 输入本机登录密码确认，再点一次 **打开**。

两个小工具第一次打开时同样操作一次。以后直接双击就行。

（macOS 15 起，右键点"打开"已经不能跳过这一步，只能按上面在系统设置里放行。）

## 三、首次配置

打开后填律所服务器地址和你的个人 Key（Key 由管理员发给你），点 **测试连接**，通过后点 **保存并进入**。

保存 Key 时，macOS 可能弹窗问是否允许访问"钥匙串"：输入本机登录密码，点 **始终允许**。Key 只存在本机钥匙串里，不写进任何文件。

## 四、在律所外使用

所内会直接连律所服务器。在律所外，需要先装好 **EasyTier 客户端**（有 Mac 版），由我方技术人员帮你配置；配好后工作台会自动改用所外地址，不用改设置。

## 五、Mac 版与 Windows 版的区别

- **暂不支持"发票整理"**：律所的发票引擎目前只有 Windows 版。首页的"发票整理"点进去会提示"Mac 版暂不支持发票整理"。
- **Word 转 PDF** 只用工作台自带的转换程序，设置里没有 Word / WPS 选项。
- 案件文件夹不要放在 iCloud 云盘、OneDrive、Dropbox 等同步文件夹里。如果开了"iCloud 云盘 → 桌面与文稿文件夹"，"桌面"和"文稿"也算同步文件夹，请另建一个本机文件夹放案件。

## 六、卸载

把三个程序拖进废纸篓即可。工作台的设置和缓存在下面两个文件夹，需要彻底清除时手动删除（在访达按 ⇧⌘G 输入路径）：

- `~/Library/Application Support/lawbench`
- `~/Library/Application Support/lawbench-desktop`

案件文件夹里的材料和成果不受卸载影响。
