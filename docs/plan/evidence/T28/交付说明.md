**偏离**

3. 小工具在 Mac 上用 PyPI 当时最新的 PyInstaller（构建工具，不进包；版本写进 `build-mac.txt`）；Windows 用的是离线钉版轮子。

**要主编排定的事**
1. **tokenizer 怎么给云上构建**：6000D 同款 `tokenizer.json`（约 20 MB，sha256 `87a7830d…`）不在仓库里，和 Hugging Face 上公开的 Qwen3 分词文件不同（11 MB，`aeb13307…`）。现在工作流设了 `LAWBENCH_ALLOW_NO_TOKENIZER=1`：照打，服务按估算计 token，**这样的包只能冒烟、不能给律师**。可选：a) 把它提交进仓库（私有库，Apache-2.0，约 20 MB）；b) 放成仓库 Release 资产，工作流按 sha256 下载；c) 律师 Mac 版一律在借来的 Mac 上本地构建。建议 b。
2. 首页"发票整理"胶囊在 Mac 上照常显示，点进去只显示"Mac 版暂不支持发票整理"（令"入口禁用并显示同一句"按这个理解）；要连胶囊一起隐藏的话再说。
