### 联调发现（交主编排派；没有顺手修）

1. **395 的连接测试 `key_valid` 为 null**（llm 是 true）。Spec 6.3 说 395 用律师 Key 校验；`connection/test` 对 prep 只报可达、不报 Key 是否有效。是设计如此（395 没有便宜的 Key 校验法）还是漏做，请定；归属 B（T3 设置与连接测试）/ C（T6 395 侧）。
2. **`ocr_pages.attempts` 在页成功时一直是 0**（4 页全部 0，含重启后续做的页）。看起来只在失败重试时加；若设计是"发送次数"，那就是没记。不影响"无重复写入"的判断（用 status 和 result_path 核的）。归属 C（T12）。
3. 识别完成后，现场勘验图文的 `pages_mixed=[1]` 照旧保留（脚本没有提交图文混排页，只提交了 `pages_need_ocr`）。符合"混排页律师自选是否识别"的话，无需处理；记一笔供 T14 界面核对。
