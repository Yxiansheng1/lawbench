**路径闸门**：
- 根目录用 realpath；根目录本身是链接或 junction，报 `CASE_ROOT_IS_LINK`。
- 云同步目录三路检测，命中报 `CASE_IN_SYNC_FOLDER`：`OneDrive*` 环境变量、注册表 `HKCU\...\OneDrive\Accounts\*\UserFolder`、目录名关键字（不分大小写）。
- AI 传入的路径拒绝以下几类：
  - 绝对路径、盘符、UNC；
  - `..`，包括 Windows 去掉尾部点和空格后等于 `..` 的写法；
  - `:`（备用数据流）、NUL、控制字符；
  - 第一级是 `.xxx`、`工作区`、`成果`，含尾部点和空格的变体；
  - 超长名（单级超过 255）、超长路径（超过 1024）。
- 逐级 lstat，遇到符号链接或 reparse point 就拒绝，指向案件内的也拒绝。
- 最终 realpath 必须以 ROOT 加分隔符开头，Windows 下不分大小写；解析后第一级落在保留目录的，再拒一次。
- 写入只限 `工作区\`、`成果\`。
- 原件区只提供"补建空文件夹"一种写法，已有的一概不动。
- 拒绝时只记操作名和原因代号。

**net.py**：
- 白名单只放行设置里四个地址的"主机+端口"，外加 `127.0.0.1`。
- `follow_redirects=False`，收到 3xx 报错；`trust_env=False`，不读系统代理。
- 地址选择：先试所内，不通试所外。6000D 探 `/v1/models`，395 探 `/health`，各 1.5 秒；结果缓存 60 秒，连接出错时重探一次，两个都不通报 `SERVER_UNREACHABLE`。
- 本机转发只接受 `POST /v1/chat/completions` 和 `GET /v1/models`，其余一律 404，不要令牌。
  - 流式透传，`Authorization`、`X-Session-Id` 原样带上，回传 `X-Queue-Wait-Ms`。
  - 连不上返回 502 + `SERVER_UNREACHABLE`。
  - 日志只记元数据。

## 5. 契约与文档

## 6. 自检与遗留

- **符号链接用例在本机跳过了 3 个**，原因是本机账号没有创建符号链接的权限（没开开发者模式）。
  - junction（同为 reparse point）的 5 个用例都跑了。

- **Windows 网络状态变化时重探地址还没做。** Spec 第 15 节要求，工单第 7 步没写。现在会重探的时机是：缓存过期、连接出错、设置改动。`Net.invalidate()` 已经留好，后续接 Windows 通知即可。
