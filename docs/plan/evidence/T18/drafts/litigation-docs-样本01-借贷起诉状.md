诉讼请求：
1. 判令被告偿还原告借款本金6万元〔推断〕；
2. 判令被告支付自2025年9月11日起至实际清偿之日止的逾期利息（按年利率百分之十二计算）〔借条 第8行〕；

事实与理由：
2025年3月10日，被告王某丙因经营资金周转需要向原告李某乙借款〔借条 第8行、借条 第29行〕，双方签订借条，约定借款金额8万元，年利率百分之十二，按月付息，到期还本〔借条 第5行、借条 第8行〕，还款期限为2025年9月10日前一次性归还全部本金〔借条 第14行〕；借款人逾期还款的，应承担出借人为实现债权支出的律师费〔借条 第17行〕。

原告于借款当日通过手机银行转账8万元给被告〔情况说明 第4行〕。

被告借款后支付了三个月利息，于2025年6月10日归还本金2万元，此后再未还款〔情况说明 第5行〕。截至起诉之日，被告尚欠原告本金6万元〔推断〕。

2025年9月10日还款期限届满后，原告多次催要，被告均以资金紧张为由拖延还款〔情况说明 第6行〕。

综上，被告未按约还款，构成违约，应承担还款责任及违约责任（法律依据待律师核实）。
