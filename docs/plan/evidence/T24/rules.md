## 二、计算规则（Spec 13.4）

| 规则 | 实现 |
|---|---|
| 折抵比例 | 管制：羁押 1 日折 2 日；拘役、有期徒刑：1 日折 1 日；指定居所监视居住：管制 1 日折 1 日，拘役、有期徒刑 2 日折 1 日，不足 1 日的部分不计、写进 notes |
| 羁押天数 | 每段按起止日含两端；各段重叠的日子只算一次（notes 注明有重叠） |
| 刑期起止 | 给了判决执行之日：起 = 执行之日，止 = 起 + 刑期 − 1 日 − 折抵天数。没给、羁押连续：起 = 羁押首日，止 = 起 + 刑期 − 1 日（比例不是 1 日折 1 日时见取法 f）。羁押不连续又没给：不算起止，notes"羁押期间不连续，请提供判决执行之日"。既没给执行之日、也没有羁押：不算起止，notes 请提供判决执行之日 |
| 刑期加法 | 先加年、再加月；加完的日期不存在时对齐到当月最后一天 |
| 执行满二分之一 | 管制、拘役、有期徒刑：刑期为偶数个整月按月折半；否则按天折半（notes"按天折半"） |
| 无期徒刑 | 不算起止、不算节点，折抵天数记 0；notes"无期徒刑的减刑、假释节点按实际执行年限计算，请律师判断" |
| 不处理 | 数罪并罚、缓刑考验期、减刑后的新刑期：本工具不接收这些输入，由 Skill 说明交律师判断（没有每次都写进 notes：契约样例的 notes 为空） |
| 折抵超过刑期 | 止日早于起日时照算，notes"刑期可能已执行完毕，请律师核实" |
| 羁押种类"其他" | 按羁押折抵，notes 请律师核实 |

## 三、Spec 13.4 没写明的取法（N4，待律师确认）

| | 取法 | 例 |
|---|---|---|
| a | 给了判决执行之日时，执行满二分之一的日期与止日一样扣折抵天数 | 用例 S04、S05、S07–S11 |
| b | 按天折半的总天数含两端：起 至 (起 + 刑期 − 1 日)；节点 = 起 + ⌈总天数 / 2⌉ − 1 日 | S02、S03 |
| c | 羁押天数取各段（含指定居所监视居住）的并集；折抵按种类分别算比例再相加；同一天既是羁押又是指定居所监视居住的按羁押算 | S09；`test_residence_overlapping_detention_counts_as_detention` |
| d | 加月只在日期不存在时对齐月末；原日期是月末的不追月末：2 月 28 日加 1 个月为 3 月 28 日（不是 3 月 31 日） | `test_month_end_start_takes_no_month_end` |
| e | 无期徒刑不断言折抵天数，本实现记 0 | S13 |
| f | 没给判决执行之日、羁押连续、比例不是 1 日折 1 日（管制的羁押、指定居所监视居住）：起 = 羁押首日，止日与节点再减"折抵天数 − 羁押天数"（为负即延后），notes 注明调整 | 管制 1 年、连续羁押 39 日：止 = 2027-03-31 − 39 日 = 2027-02-20；有期 1 年、只有指居 31 日（折 15 日）：止日延后 16 日为 2027-03-16 |
