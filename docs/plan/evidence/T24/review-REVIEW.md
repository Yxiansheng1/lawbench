**P3-2 日期超出 Python 能表示的范围时返回内部错误**
- **问题**：输入合契约但日期离谱时报的是内部错误，不是参数错误。例如 `{"penalty":"有期徒刑","years":25,"execution_start":"9999-01-01","custody":[]}`，或者管制、执行之日 `0001-01-02`、羁押整个 0001 年。这两种经 `/core/tool` 都返回 HTTP 500 `INTERNAL`，而不是 `INVALID_ARGUMENT`。日志只记了异常类名，没有泄露数据。
- **最小修复**：在 `calc()` 里对日期运算捕获 `OverflowError` 和 `ValueError`，转成 `ApiError("INVALID_ARGUMENT", "date_out_of_range")`。
- **归类**：独立后续（输入极端，实际很难碰到）。
