## 6. 自检、遗留与模糊条款

**试跑中的发现（请主编排决定是否上候 owner 清单；我没有对服务器做任何改动）**
- `port_scan.py`（所内地址）：6000D `192.168.8.77` 除 8000、22 外还开放 **8080**；395 `192.168.8.124` 除 22、3389 外还开放 **80、135、8080**，而 9000 暂时连不上（prep395 尚未部署，T11）。Spec 6.1 要求 395 防火墙入站只放行 9000，SEC-13 要求"局域网不能绕过网关"。8080 上跑的是什么我没有探查。所外地址本机当时连不上，没测。
- `key_check.py`：6000D 不带 Key、带错误 Key 都返回 200（已知，Spec 6.3）。

**Spec / 工单没写明、我采用的做法**
- (a) "抓包"用两层：`net_watch.ps1`（按进程记录 TCP 远端地址，无需装软件）作为脚本，`manual\抓包.md` 用 Windows 自带 `pktmon` 抓全量包作为正式证据。`net_watch.ps1` 看不到 UDP 和不经 DNS 缓存的解析，所以不能单独判第 1 项。
- (b) "无 Key / 停用 Key"：6000D 无 Key 也返回 200 时判"前提不满足"，不判不通过；停用 Key 需要管理员在网关停用一个测试 Key 并放进环境变量 `LAWFIRM_REVOKED_KEY`。
- (c) "395 残留检查（SSH 到 395 执行搜索）"：按项目纪律 AI 不保存、不索要 SSH 密码，改为脚本打印命令、用户在 395 上执行、结果文件交回脚本判定。6000D 的残留检查同理（`manual\6000D残留检查.md`）。
- (d) `find_leaks` 按字节搜 UTF-8 / UTF-16LE；docx、zip 等压缩文件里的内容搜不到——SEC-01 要查的是解压后的正文副本（材料文本、数据库、会话记录）有没有落到案件外，这些都是明文。
- (e) `port_scan.py` 把 22（SSH）、3389（远程桌面）列为"注意"不判不通过，因为 Spec 6.1 说远程桌面保留、SSH 是运维入口，是否保留由甲方决定。
- (f) `dsh_locations.py` 的 `$DSH_HOME` 缺省取环境变量，没有时取 `%USERPROFILE%\.dsh`；DSH 实际的数据目录名要等 T2 / T17 核实后对齐。

**遗留**
- `find_leaks.py` 在开发机上扫整个用户目录太慢（15 分钟以上未完成；只扫 %APPDATA% 也超过 20 分钟）。验收机较干净，可能可接受；否则需要加进度输出、按目录分批或排除浏览器缓存等大目录（排除会影响覆盖面，需主编排定）。
- T17 合并后，`find_leaks.ps1` 改为调用 `scripts\find_leaks.ps1`（工单要求）。
- 工作台服务相关脚本（案件隔离、云同步）要在 T3 合并后用真实接口复跑一次，确认 `/core/tool`、`/api/case/open` 的失败体形状与脚本的判断一致（脚本以"返回里是否出现案件 B / win.ini 内容"和 `ok` 字段判定）。
- 发票调用代码（T25）出来后，`engine_net_inventory.py` 才能给出"通过"。

## 7. 小修（2026-09-29，依据 `ORCH-广播-无人值守开窗-20260929-2021.md` 线 C 小修一节）

- `find_leaks.py`：按顶层目录分批——每个根目录的顶层文件算一批，每个顶层子目录各算一批。每扫完一批打印一行，写明文件数、命中数和耗时；每批结果单独写进证据目录下的 `find_leaks-<参数摘要>\批NNNN.txt`，进度记在同目录的 `进度.json`。中断后用同样的参数再运行，自动从没扫完的那一批继续；`--fresh` 从头来。按裁决不排除任何目录。`find_leaks.ps1` 同步加了 `-Fresh`。
- 演示：`resume-demo.txt`。第一次全扫，命中目录外的泄露副本；再从进度文件删掉一批模拟中断，用同样参数再跑，只重扫了那一批，结论不变。
- 实测：在开发机上扫 `%APPDATA%` 共 61 批，每批一行进度正常输出。单文件平均约 18 毫秒（例如 Adobe 目录 816 个文件用了 14.8 秒），推测是每次打开文件都被杀毒软件扫描；慢，但现在能看到进度，也能分次跑完。
- `acceptance\README.md`：写明 `net_watch.ps1` 看不到 UDP 流量，也看不到不经本机 DNS 缓存的解析，不能单独判第 1 项，判定以 `manual\抓包.md` 的全量抓包为准。
