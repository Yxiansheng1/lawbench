# T7 小项：测试辅助 tests\helpers\fake.ts 的端口（主编排 2026-09-30 04:41 注记）

问题：startFake 用调用方给的固定端口（如 trial-connection 用 18801），只看 /health 就算就绪。
桌面端开着时 Host 的假服务可能正占着同一端口，测试就连到了别人起的服务（令牌不同），
2026-09-30 04:20 实测 trial-connection.spec.ts 13 项失败（"Unexpected end of JSON input"），关掉桌面端即全过。

改法：
- 先试给定端口，被占就在线 A 的端口段 18801–18809 里挑空闲的；都不行就报错
  "假服务起不来：18801–18809 没有可用端口……"，不连别人的服务。
- 就绪判断改为用自己的令牌访问要鉴权的 GET /api/settings，必须回 200；别人的服务令牌不同，回 401，不会被当成自己的。
- 端口在检查之后被抢走、或子进程退出时，换下一个端口。

验证（2026-09-30）：
- 另起一个"占位服务"在 18801 上，/health 回 200、其余回 401（模拟桌面端的假服务）；
  此时跑 trial-connection.spec.ts：14 项全过（改前同样情形 13 项失败）。
