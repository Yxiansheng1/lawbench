## 二、问题（按严重度）

**F1 · P3 · 冻结清单内未关闭（NOTE-1 的一部分）· 阻断**
- 问题：配置目录删不掉、同时本次转换失败时，那条提示会丢掉，用户看不到。
- 原因：`core.py:194-195` 把提示加进 `convert_file_ex` 里的局部 `notes`（238 行）。转换抛出 `ConvertError` 或其他异常时，`convert_many`（352-358 行）用的还是自己那个空的 `notes`，提示随异常一起丢了。界面 `app.py` 的 `show()` 本来就会给失败的文件显示提示，丢是丢在 core 这一层。
- 影响：最容易删不掉配置目录的恰恰是失败的时候，比如超时后有子进程逃出进程树还占着文件。这时残留会被静默留下，不符合 Spec 5.2。
- 证据：`rv-C6-lab\note1-clone.txt`，第二行的结果是 `[B-失败] … notes=[] has_PROFILE_LEFT=False … profile_left=['jgy2jw1r']`。
- 最小修复：让 `convert_many` 把每个文件的 `notes` 列表传进 `convert_file_ex`（比如加一个可选参数，由调用方持有这个列表），失败时也保留；补一个"转换失败加删不掉 → 失败原因里带着这条提示"的测试。
