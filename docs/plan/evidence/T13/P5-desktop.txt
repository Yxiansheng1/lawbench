# P-5 桌面端实测（开发模式、假工作台服务 --fixtures、临时假 Key 测后已清掉，演示案件目录与拖入的虚构文本测后已清掉）

1. 打开案件的新会话：输入框左下没有"+"按钮（页面上查 aria-label=添加文件或调用指令 的元素：没有）。截图 P5-01。
2. 从资源管理器拖一个文件到对话输入框（CDP Input.dispatchDragEvent，真实拖入事件）：弹"导入材料"确认框，输入框里没有引用标签，也没有"没有加进对话"的守卫提示（P-5 接上后守卫让路）。截图 P5-02。
3. 点"复制到案件并解析"：假服务收到导入请求（调用记录摘录，只有元数据）：
   {"ts":"2026-09-30T02:48:09.832Z","method":"POST","path":"/api/materials/import","status":200,"ms":16,"ok":true} {"ts":"2026-09-30T02:48:09.870Z","method":"GET","path":"/api/materials","status":200,"ms":1,"ok":true} {"ts":"2026-09-30T02:48:09.872Z","method":"GET","path":"/api/ocr/jobs","status":200,"ms":1,"ok":true}
   截图 P5-03（导入结果为假服务的固定样例，路径是虚构的）。
4. 切到默认工作区里的会话（不在已登记案件里），拖入：顶部提示"材料只能导入到案件里。请先从首页打开案件，再把文件拖进来。"，输入框里没有标签。截图 P5-04。
5. $DSH_HOME\attachments：测试前 0 个文件，测试后 0 个文件。

没有实测：粘贴文件（CDP 没有往剪贴板放文件的办法；粘贴也走 addFiles，由 DSH 侧用例和我方 intake 覆盖）、"/file"命令选文件（同走 addFiles）。
