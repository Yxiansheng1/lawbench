## 3. 做法

**识别出处**（`parse.find_cites`）：正文里每个〔…〕先判断是不是出处——引号（“”、""、「」）内的〔〕是引语原文的一部分，内容只有 4 位数字的〔〕是公文文号的年份（"虚公刑诉字〔2026〕417号"），这两种不算；其余一律按契约 `citation_text` 正则判，不合格报 E。正则在运行时从 `contracts\common.schema.json` 读，代码里不另写（执行令硬要求，有测试核对两者逐字相同）。N45（材料名里带〔〕）照旧留契约 1.4。形如【材料名 第N页】的报 E（formats.md 第 3 节）。

**切分**：逐行。行内每组相邻出处（中间只隔空白和"；;、，,"）管它前面那段文字；表格行整行一段；引用块（> 开头）整段按引语核。标题、表格分隔行、HTML 注释、代码块跳过。

**材料与位置**：`MaterialSet.from_case(root, index)` 只读 `index.json` 和材料文本（`texts.read_text`，过闸门），不碰原件区；只在某份材料被引用时才读它的文本。位置文本：页、段、行取对应单元（范围取多个）；单元格取显示值（材料文本里的"反斜杠加竖线"还原成竖线、`<br>` 还原成换行），区域取区域内各格。别处查找时 Excel 按单个单元格定位（报"实际在 流水!B2"）。

**比对口径**（裁决 3）：文本先过 T9 的 `search.normalize.normalize`（直接 import，没复制）。金额按值：`Decimal` 计算（18 位证件号不丢尾数），万、亿换算，千分位、全角已由归一化处理；小于 4 位的整数（页码、人数）不查；带 ■ 的数不比。日期按年月日，原文只写月日、月份（"3月底""5月份"）时按月比。只写年份的"1981年"按年份比：原文里带年份的日期也算有这个年份（文中"1981年出生"核得到原文"1981年6月出生"；wiki 脚本会把它报成找不到）。数字中间的换行先去掉（PDF 取文字会在数字中间折行，criminal-01 起诉意见书第 4 页"12\n6,500"）。公文文号"〔2026〕417号"不当数值核。中文数字金额第一版不比对、不出问题（裁决 4；Spec 9.4 已由主编排改）。

**七类**：

| 类 | 判定 | 严重度 |
|---|---|---|
| A | 所标位置原文里识别不清的数（`8■,000.00`）或姓名（`陈美■`），文中写成了完整值 | must_fix |
| B | 金额、日期、引语不在所标位置，但在所引材料别处 | must_fix |
| C | 所引材料哪里都没有 | must_fix |
| D | 只在调用方给了 `declared`（声明引用的材料名）时查：引用了不在其中的材料。`case_save_draft` 不给、不查（裁决 1）；wiki 流水线用不用由 T16 定 | must_fix |
| E | 不合正则；【】写出处；材料名不存在；位置与材料的定位方式不合（段落材料写了"第N页"）；号从 1 起；超出范围；范围写反；工作表不存在 | must_fix |
| F | 含金额或日期但没带出处（〔推断〕〔未找到依据〕标注的不算） | hint |
| G | 评价性用语（词表同 wiki 脚本），出处和引号内的原文不算；整句已标"待律师核实"且没有证据评价、动机推测词的不报。`excerpt` 必须修改；`analysis`、`draft` 只提示、提示语要求标明"分析意见" | 按 kind |

〔推断〕〔未找到依据〕所在那段不核 A、B、C。没有材料文本的材料（失败、未就绪）只核出处格式与位置写法，不核内容，出处照样记入 `citations`。

**引语**（裁决 2，阈值见第 5 节）：引号内原文、引用块正文，归一化并去掉全部空白后 ≥6 字的核；含 ■ 的不核。所标位置找不到：所引材料别处找到报 B，哪里都没有报 C。"未被引用的 raw 文件"清单没搬。

**kind**（裁决 6）：按任务的 `skill` 读 `<Skill 目录>\<skill>\SKILL.md` 头部的 `kind:`；skill 为空、名字不是 `[A-Za-z0-9_-]+`（不拼路径）、文件不在或值不认识，都按 `analysis`。

**结构化出处**（裁决 6）：每处合格、材料存在、位置合法的出处记一条 `{material_id, material_version, name, loc}`，`material_version` 取 `index.json` 的 sha256；`result.json.citations` 是本任务全部草稿的出处，按（材料编号、位置）去重。`stats.citations` 是本篇里合格出处的处数（重复引用也计）。

**日志**：只记 `checks/draft`、案件编号、耗时；不记出处原文、草稿内容（有测试）。

## 6. 遗留与发现

- **材料文本里以【开头的行会被当成位置标记，正文丢失**（大卷宗对照时发现，不在本卡范围）：`case\texts.py` 的 `_MARK` 认所有行首的【…】，微信、短信导出（"【2025-03-10 21:14】周立新：…"）这类行会被吞掉，`case_read_material`、检索、出处核对都受影响。修法二选一：T5 写材料文本时转义行首的【，或 `split_units` 只认"第N页/段/行"和"表:…"两种标记。交主编排定。
- 跨两页的引语，如果出处只标了一页，在"别处"按单页找也找不到，会报 C 而不是 B（位置写成"第2-3页"就能核到）。
- 中文数字金额不比对（裁决 4，T18 实测后定）。
- 原文只写年龄、文中换算成出生年份的，会报 C（换算值原文里没有）。
- 只写年份（"王某2025年出生"）时，所标那页只要有任何一个同年的日期就算核到（复核 NOTE，主编排接受为已知限制）；写了月份的照常按年月比。
- 一处出处引了两个位置、其中一个位置这类值只用中文数字写时，这条值整条不核（另一个位置的阿拉伯数字写错也不报）（第二轮复核 NOTE，注记 1644 定为已知限制）。
- 『』只在比较引语时与别的引号算同一个字符，没有算进"引号"：『』里的错引语不核，『』里的评价词会报 G（第二轮复核 NOTE，同上）。
