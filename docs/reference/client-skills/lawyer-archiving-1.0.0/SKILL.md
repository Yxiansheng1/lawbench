# 律师案件电子归档

## 依赖与配置

本技能依赖以下外部工具/库，使用前请确保已安装：

- **LibreOffice（`soffice`）**：把 docx 等非 PDF 材料批量转为 PDF。macOS：`brew install --cask libreoffice`；调用方式 `soffice --headless --convert-to pdf --outdir <输出目录> <文件>`。
- **Python 3.13（WorkBuddy 托管）**：路径 `/Users/huangmengsha/.workbuddy/binaries/python/versions/3.13.12/bin/python3`。
- **python-docx**：填写/生成结案报告、立卷申请书 Word 模板。安装：`pip install python-docx`。
- **PyMuPDF（`fitz`）**：合并卷宗 PDF、添加页码。安装：`pip install PyMuPDF`。

> 注：结案报告、立卷申请书的最终精准排版建议在 WPS 中“另存为 PDF”；LibreOffice 转出的 PDF 仅作卷宗合并的临时占位（立卷申请书走“打印→手签→扫描”流程，不强制软件转 PDF）。

## 概述

按照广东连越（深圳）律师事务所《律师业务档案立卷归档办法》及电子归档指引，辅助律师从案件项目文件夹中提取材料，生成金助理系统上传所需的 3 个归档文件。

**最终产出（上传金助理的 3 个文件）：**

| 文件 | 说明 |
|------|------|
| `发票.pdf` | 收费发票凭证 |
| `立卷申请书.pdf` | 附件3（民事行政）/ 附件2（刑事）/ 附件4（常法）/ 附件5（其他非诉），需打印手签后扫描 |
| `卷宗.pdf` | 全部归档材料按编号顺序合并的 PDF |

**归档总文件夹命名规则（强制）**：本技能产出的 3 个归档文件必须放入一个以本案当事人命名的总文件夹，命名格式为：

```
xxx（当事人名称）与xxx（如有对方当事人名称）案件归档
```

- 当事人名称 = 委托人全称（如「深圳市柏裕国际物流有限公司」）
- 对方当事人名称 = 对方当事人全称（如有；无对方当事人时省略「与xxx」整段）
- 示例：
  - 有对方当事人：`深圳市柏裕国际物流有限公司与广州盈恒供应链管理有限公司案件归档`
  - 无对方当事人（如常法卷）：`XX有限公司案件归档`
- 该总文件夹即上传金助理的「结案」目标文件夹，下文统称「归档总文件夹」。

## 工作流程

### 第一步：了解案件基本情况

1. **读取项目 CLAUDE.md**（项目根目录的 `CLAUDE.md`），提取：当事人信息、案由、案号、管辖法院、关键日期等。

2. **自动提取以下信息**（优先从材料中提取，提取不到再问律师）：

   | 信息 | 提取方式 | 提取不到时 |
   |------|----------|------------|
   | 承办律师 | 固定为「黄梦莎」，无需询问 | — |
   | 律师费 | 默认已结清，无需询问。除非用户明确说未结清 | — |
   | 委托日期 | 查看委托合同的创建时间（`ls -la` 看文件日期），一般在合同签订前后 | 问律师 |
   | 结案日期 | 从最后一份法院文书的落款日期提取（裁定书/判决书末尾的日期） | 问律师 |
   | 金助理编号 | 从 CLAUDE.md 或律师处获取 | 问律师 |
   | 案件类型 | 根据案由和材料判断：刑事/民事行政/法律顾问/其他非诉 | 问律师 |

3. **向律师确认以下信息**（这些无法自动提取）：
   - **办案结果**：⚠️ 绝对不要自己猜！必须让律师确认。特别注意：要搞清楚你代理的是哪一方，原告胜诉不等于你方胜诉。
   - 归档材料是否完整（有无缺失）

   提问方式示例：
   > "根据材料，本案为【案由】，你方代理【委托人】。关键信息：
   > - 委托日期：从委托合同提取为 YYYY-MM-DD
   > - 结案日期：从【最后文书】提取为 YYYY-MM-DD
   > - 金助理编号：？
   > - 办案结果（你方视角）：胜诉/败诉/调解/撤诉/部分胜诉？"

### 第四步：生成结案报告

结案报告为一页纸的简要报告，模板结构如下（参见 `templates/结案报告模板.docx`）：

```
结案报告

一、当事人/委托人：【委托人全称】
对方当事人：【对方当事人全称】

委托日期：【YYYY-MM-DD】

结案日期：【YYYY-MM-DD】

承办律师：黄梦莎

案由：【案由全称】

案情简介：【委托人】因【案由】等事宜向我方委托人申请【仲裁/起诉/应诉】。

承办律师分析与意见：委托人有权【对/向】【对方当事人】主张【诉求】。

八、办案结果：【胜诉/调解/撤诉/部分胜诉/其他】
```

#### 填写规则

- 所有信息必须来自 CLAUDE.md、案件材料或律师确认，不得编造
- 民事/行政案件：「案情简介」从起诉状/答辩状提炼，「分析与意见」从代理策略提炼
- **常法案件**：用「服务概况」替代「案情简介」，「服务结果」替代「办案结果」；对方当事人栏写「无（常年法律顾问）」
- 办案结果必须在律师确认后再填写

#### 生成方式

使用 python-docx 读取 `templates/结案报告模板.docx`，将段落中所有 `【...】` 占位符替换为实际内容。注意模板中占位符 `【        】` 的空格数量可能不一致，替换时用正则匹配 `【[^】]*】` 来定位。

```python
import re
from docx import Document

doc = Document('templates/结案报告模板.docx')
replacements = {
    '【        】': '深圳市柏裕国际物流有限公司',  # 第一个出现=委托人
    # ... 按出现顺序依次替换
}
# 更稳健的做法：收集所有段落文本，按顺序替换【】占位符
```

保存为 `结案报告.docx`。⚠️ 结案报告需要精准的 1 页排版。

**1 页排版策略**（按优先级尝试）：
1. **首选**：用模板 `结案报告模板.docx`，清理多余空行（空段落间距压缩到 0.2 倍行距、字号缩到 2pt），保持原字体 12pt 不变，通常即可 1 页。
2. **备选**：如果内容较长（如案情简介+分析意见超过 4 行），用 python-docx 直接写入，11pt 字体、1.1 倍行距，无需模板。
3. **最终兜底**：LibreOffice 字体与 WPS 不一致可能造成分页偏差，**最终 PDF 请在 WPS 中「另存为 PDF」**。LibreOffice 转的 PDF 仅作为卷宗合并的临时占位。

```python
# 备选方案：python-docx 直接写入（11pt）
from docx import Document
from docx.shared import Pt, Cm
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml.ns import qn

doc = Document()
for s in doc.sections:
    s.top_margin = Cm(1.8); s.bottom_margin = Cm(1.2)
    s.left_margin = Cm(2.2); s.right_margin = Cm(1.8)

def P(text, font='仿宋', size=Pt(11), bold=False, align=WD_ALIGN_PARAGRAPH.LEFT, indent=None):
    p = doc.add_paragraph()
    p.alignment = align
    pf = p.paragraph_format
    pf.line_spacing = 1.1
    pf.space_after = Pt(1); pf.space_before = Pt(0)
    if indent: pf.first_line_indent = indent
    run = p.add_run(text)
    run.font.name = font
    run._element.rPr.rFonts.set(qn('w:eastAsia'), font)
    run.font.size = size; run.bold = bold

P('结案报告', '黑体', Pt(16), True, WD_ALIGN_PARAGRAPH.CENTER, after=Pt(8))
P('一、当事人/委托人：XXX', '黑体', Pt(11), True, before=Pt(3))
P('对方当事人：XXX')
# ... 依次填写各项
doc.save('结案报告.docx')  # 最终随卷宗合并；如需单独存放可放入归档总文件夹
```

#### 6.2 按归档编号排序

合并顺序严格按归档目录的编码排列。例如民事行政卷的顺序为：

```
编码1 → 委托代理合同
编码2 → 收费发票凭证

编码4 → 起诉书/答辩书
```

#### 6.3 合并 PDF

⚠️ **关键**：合并时必须按归档编码逐项合并，并记录每项的起始页码，供立卷申请书标注页码范围。

```python
import fitz, os

# 按编码逐项合并，记录页码范围
groups = [
    ("委托合同", ["合同.pdf"]),
    ("发票", ["发票.pdf"]),
    ("授权委托书", ["授权委托书.pdf", "所函.pdf"]),
    ("起诉书", ["起诉状.pdf"]),
    ("证据材料", ["证据1.pdf", "证据2.pdf", ...]),
    ("判决书/调解书", ["调解书.pdf"]),
    ("结案报告", ["结案报告.pdf"]),
]

vol = fitz.open()
page_ranges = []

for label, files in groups:
    start = vol.page_count + 1
    for f in files:
        if os.path.exists(f):
            doc = fitz.open(f)
            vol.insert_pdf(doc)
            doc.close()
    end = vol.page_count
    if end >= start:
        page_ranges.append((label, start, end))

# 保存（先不加页码）
vol.save('卷宗_无页码.pdf')
```

#### 6.4 添加页码

卷宗必须添加页码（底端居中「第x页 共x页」），同时用白底遮罩覆盖原文档可能自带的页码：

```python
vol = fitz.open('卷宗_无页码.pdf')
total = vol.page_count

for i in range(total):
    page = vol[i]
    h = page.rect.height; w = page.rect.width
    # 白底遮罩覆盖原页码区域
    page.draw_rect(fitz.Rect(0, h-55, w, h), color=None, fill=(1,1,1), width=0)
    # 新页码
    page.insert_textbox(
        fitz.Rect(0, h-40, w, h-20),
        f"第{i+1}页 共{total}页",
        fontname="china-s", fontsize=10,
        align=fitz.TEXT_ALIGN_CENTER,
    )

vol.save('卷宗.pdf', garbage=4, deflate=True)
vol.close()
```

页码在 PDF 阅读器中显示干净，遮罩会覆盖原文档中的旧页码。

#### 7.3 按实际材料修改描述，并标注页码范围

模板中的描述是通用的，必须按本案实际材料修改。**每项材料名称后必须标注卷宗中的页码范围**：

- **去掉括号备注**：如「（合同编号、经办律师签字、落款时间必填）」是检查提示，不入最终文书
- **材料名称反映实际内容**：如编码 14 模板写「判决书、裁定书、调解书、上诉书」，但本案只有仲裁裁决书 + 判决书 + 裁定书，就改成「仲裁裁决书、民事判决书、民事裁定书」
- **标注页码**：根据第六步合并时记录的 `page_ranges`，在每项描述后追加页码范围

```python
# 根据 page_ranges 更新描述
page_info = {

# 更新表格中对应行的描述
for i in range(1, len(table.rows)):

        cell.paragraphs[0].runs[0].text = f'* 材料名称 {page_info[orig_num]}'
```

⚠️ **P5 占位符跨 run 问题**：模板中 `【（金助理系统案件编号+客户名称）】` 长年法卷模板会拆成 5 个 run（`【`、`（`、`金助理系统`、`案件编号+客户名称）`、`】`），不能用 `replace` 整段替换。正确做法是清空前 5 个 run 再写入：

```python
for p in doc.paragraphs:
    if '金助理系统' in p.text:
        p.runs[0].text = '（编号+客户名称）'
        for i in range(1, 5):
            p.runs[i].text = ''
        break
```

#### 7.4 统一表格字体

表头保持黑体，内容行统一为仿宋 12pt（小四），去掉加粗：

```python
for i, row in enumerate(table.rows):
    if i == 0: continue  # 跳过表头
    for cell in row.cells:
        for p in cell.paragraphs:
            for run in p.runs:
                run.bold = False
                run.font.name = '仿宋'
                run.font.size = Pt(12)
```

## 重要提醒

1. **不编造事实**：结案报告中的所有信息均来自 CLAUDE.md、案件材料或律师确认。
2. **委托合同必须是盖章 PDF**：归档用的委托代理合同必须是盖章扫描版 PDF。如果只有 docx，务必向律师索要盖章版 PDF。
3. **办案结果必须律师确认**：结案报告中的「办案结果」绝对不能自己判断。必须搞清楚代理立场——原告胜诉不等于你方胜诉，要看你代理的是哪一方。
4. **PDF 转换策略**：卷宗中的 docx（起诉状、答辩状等）用 LibreOffice 批量转 PDF；结案报告在 WPS 中另存为 PDF 确保 1 页精准排版；立卷申请书走「打印→手签→扫描」不需要软件转 PDF。
5. **不处理混乱文件**：只匹配命名规范的文件。混乱命名的文件（如 `微信图片_xxx.jpg`、`~$` 临时文件）、加密 PDF、Apple Double 文件（`._` 开头）视为无效，不纳入归档。
6. **卷宗 PDF 合并顺序**：严格按归档目录编码排列，同编码内按阶段排序（仲裁→一审→二审→再审），缺失项跳过不留空白页。
7. **手签要求**：立卷申请书、特殊情况说明必须由经办律师手签，不得代签、不得电子签。
8. **时效要求**：案件结案后 3 个月内完成归档。如已超期，提醒律师尽快办理。
