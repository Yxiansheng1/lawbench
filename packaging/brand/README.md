# 品牌素材

把以下文件放在本目录（`D:\lawbench\packaging\brand\`），打安装包（工单 T20）时直接使用；缺哪个就用占位图。

| 文件名 | 内容 | 要求 |
|---|---|---|
| `firm-logo.png` | 律所 logo（主品牌） | 透明背景 PNG，宽度不小于 512 像素 |
| `firm-logo.svg` | 律所 logo 矢量版（有就放） | 可选 |
| `vendor-logo.png` | 我方公司 logo（"技术支持"） | 透明背景 PNG，宽度不小于 256 像素 |
| `app-icon.png` | 软件图标 | 正方形，1024×1024 PNG；没有就用律所 logo 裁成方形 |
| `names.txt` | 第一行律所全称，第二行软件名称 | UTF-8 文本 |

原始文件名不同也可以，放进来后告诉主编排对应关系即可。
