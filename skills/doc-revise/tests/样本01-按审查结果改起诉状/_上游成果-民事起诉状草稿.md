# 民事起诉状

原告：李某乙，男，公民身份号码990103197901010000（虚构），住虚构市虚构区不存在街8号，联系电话【待补充：原告联系电话】。〔借条 第7段〕

被告：王某丙，男，公民身份号码990104198203030000（虚构），住虚构市虚构区无此巷16号。〔借条 第7段〕

## 诉讼请求

一、判令被告归还借款本金人民币陆万元（￥60,000.00）；

二、判令被告以 60,000 元为基数，自 2025年9月11日起按年利率百分之十二支付逾期利息至实际清偿之日止；

三、判令被告承担原告为实现债权支出的律师费【待补充：律师费金额】；

四、本案诉讼费用由被告承担。

## 事实与理由

原告与被告系朋友关系。2025年3月10日，被告以经营资金周转为由向原告借款人民币捌万元整（￥80,000.00），原告当日通过手机银行转账支付，被告出具借条一份〔借条 第2段、银行流水 第4行〕。借条约定借款日期为2025年3月10日〔借条 第5段〕，年利率为百分之十二，按月付息〔借条 第4段〕，还款期限为2025年9月10日前一次性归还全部本金〔借条 第5段〕。

借款后，被告支付了部分利息，并于2025年7月10日归还本金20,000元〔还款记录 第5行〕。此后王某斌再未还款，至今尚欠本金65,000元。

还款期限届满后，原告多次催要，被告均以资金紧张为由拖延〔情况说明 第6行〕。被告恶意逃债、人品低劣，严重损害了原告的合法权益。

根据《中华人民共和国民法典》第六百七十六条的规定，借款人未按照约定的期限返还借款的，应当按照约定或者国家有关规定支付逾期利息。借条同时约定借款人逾期还款的应承担出借人为实现债权支出的律师费〔借条 第6段〕。为维护原告合法权益，特诉至贵院，望判如所请。
