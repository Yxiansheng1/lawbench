# doc-revise 测试要点

- 样本里 `_上游成果-*.md` 运行时选作 L1 任务输入（要改的草稿，或出稿前审查结果），不作为材料导入；其余文件（`_任务说明.md` 除外）是案件材料，材料名 = 文件名去掉扩展名。
- 位置：材料文本里有【第N页】/【第N段】标记的按标记计；没有标记的 .txt 按行号计（文件第一行为第1行）。
- `_任务说明.md` 只把"律师在对话里的原话"那一段交给模型。
- 通用判分：输出"修改说明表＋修改后全文"；意见之外的段落逐字比对不得变化（出处核对引起的出处改正除外，须列入说明表）；人名、金额、日期、原文引语保持原样。
