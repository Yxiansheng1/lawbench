# 关于提前解除物业服务合同的法律意见书

致：虚构市某某虚构科技有限公司

## 一、委托事项和需要回答的问题

贵司拟提前解除与虚构市某某虚构物业服务有限公司的物业服务合同，需要回答：（一）能否依合同约定解除；（二）解除程序；（三）暂扣的第四季度服务费是否需要支付。

## 二、出具依据

物业服务合同、往来函件、会议纪要。本意见以上述材料真实、完整为前提。

## 三、基本事实

1. 合同约定服务期限自2025年1月1日起至2027年12月31日止〔物业服务合同 第4段〕；另有条款写"本合同有效期两年"〔物业服务合同 第14段〕，两处不一致。
2. 合同约定乙方连续两个季度考核不合格的，甲方有权解除，但应提前30日书面通知〔物业服务合同 第9段〕。
3. 第三季度考核得分72分，不合格，通知已由物业项目经理签收〔往来函件 第1页〕。
4. 第四季度考核得分75分，不合格〔往来函件 第2页〕。
5. 贵司暂扣第四季度服务费合计109,500元〔往来函件 第2页〕；合同约定不合格时可暂扣当季服务费的20%〔物业服务合同 第8段〕。
6. 物业方项目经理钱某庚称第三季度问题已全部整改〔会议纪要 第6行〕。

## 四、法律分析

（一）解除条件。乙方已连续两个季度考核不合格，满足合同约定的解除条件（法律依据待律师核实）。

（二）解除程序。应提前30日向乙方发出书面解除通知，并保留送达证据〔物业服务合同 第9段〕。

（三）暂扣服务费。暂扣金额超过合同约定的20%比例〔推断〕，超出部分存在被要求支付的风险（法律依据待律师核实）。

## 五、结论意见

（一）贵司可以依合同约定解除。
（二）应提前30日书面通知乙方并保留送达证据。
（三）暂扣金额中超过约定比例的部分建议支付或与物业方协商。
