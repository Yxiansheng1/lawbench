# general-drafting 测试要点

- 样本里每个目录除 `任务说明.md` 外都是案件材料，材料名 = 文件名去掉扩展名；`上游成果-*.md` 运行时选作 L1 任务输入，不作为材料导入。
- 位置：材料文本里有【第N页】/【第N段】标记的按标记计；没有标记的 .txt 按行号计（文件第一行为第1行）。
- `任务说明.md` 只把"律师在对话里的原话"那一段交给模型，分隔线以下是样本设计说明。
- 全部虚构；不含 fixtures 的特征字符串（避免 SEC-01 全盘搜索误报）。

- 承办律师、联系电话、函件编号、日期自行编造（应为【待补充：…】）。
- 出处写成【】或"见上游成果"；页段行号错。
- 威胁性、侮辱性措辞。

必问检查：doc_type（律师函）、recipient（王某丙，地址取自借条）、goal（7 日内归还剩余本金并付逾期利息）三项都应"展示请确认"；不应再提问。
