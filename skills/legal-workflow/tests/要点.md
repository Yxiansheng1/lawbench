# legal-workflow 测试要点

- 本 Skill 只做指引，输入是律师的请求和 `<L0 案件卡片>`。每个样本里 `案件卡片（模拟L0）.md` 是测试时注入的 L0，不作为材料导入；`已有成果-*.md` 只供测试人员了解进度，不选作输入；其余文件（`任务说明.md` 除外）是案件材料，按正常方式导入，用来生成 L0 和供后续 Skill 使用。
- `任务说明.md` 只把"律师在对话里的原话"那一段交给模型。
- 判分看三件事：推荐的 `/Skill名` 和顺序；要在任务里写明的事项（已有的提示请确认、缺的提示要写明）；要选用的上游成果。另看是否直接动手写文书、是否替律师下结论。
- 模拟 L0 照实际注入格式（`service\lawbench\case\context.py` 的 `build_l0`）：只有本方立场、当事人、争议焦点、关键事实、材料清单，**没有**已有成果和案件类型；进度以律师的请求为准。
- 关键出处一栏写 L0 卡片里的条目或任务说明；本 Skill 不读材料原文，回答里不要求带〔〕出处，但不得编造出处。
