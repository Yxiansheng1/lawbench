# 证据审查意见（孙某戊涉嫌故意伤害案）

## 一、言词证据
1. 被害人钱某庚称孙某戊"站起来就是一拳"，否认先动手，但承认手里拿着酒瓶〔被害人陈述 第1页〕。
2. 证人李某辛称钱某庚先拿啤酒瓶砸孙某戊头部，孙某戊才还手〔证人证言 第2页〕；李某辛与孙某戊系同事，存在利害关系，证言证明力需结合其他证据判断（法律依据待律师核实）。
3. 证人周某壬未看到谁先动手，但看到孙某戊头上也有血〔证人证言 第1页〕。
4. 卷中未见孙某戊头部受伤的病历或伤情鉴定〔未找到依据〕。

## 二、鉴定意见
1. 委托日期 2026年5月18日，距受伤约两个半月〔鉴定意见书 第1页〕〔推断〕。
2. 检材中 CT 片的拍摄时间识别不清（"伤后■日"），需核对原件〔鉴定意见书 第1页〕。

## 三、到案与赔偿
1. 经民警电话通知后到案〔起诉意见书 第2页〕；是否构成自首待律师判断。
2. 家属赔偿 2 万元，被害人暂不谅解〔被害人陈述 第2页〕。
