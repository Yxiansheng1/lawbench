庭审笔录
案号：（2026）虚0103民初2580号
案由：房屋租赁合同纠纷
时间：2026年9月16日 9:30
审判员：邹某甲　书记员：喻某乙
原告：林某丙，委托诉讼代理人：某某虚构律师事务所律师 柳某
被告：虚构市拾味餐饮有限公司，委托诉讼代理人：苗某丁

【第2页】
审：原告陈述诉讼请求。
原代：请求判令被告支付2025年10月至12月租金共36,000元，及逾期付款违约金；解除双方租赁合同。
审：被告答辩。
被代：被告确实没有支付这三个月的租金，但原告在微信里同意过延期到年后再付，所以被告不构成违约，原告无权解除合同。
审：根据双方陈述，本庭归纳争议焦点如下：一、原告是否同意被告延期支付2025年10月至12月的租金；二、原告是否有权解除租赁合同。双方有无异议？
原代：无异议。
被代：无异议。

【第3页】
审：被告对证据三微信聊天记录的质证意见？
被代：真实性认可。原告说"年后再说吧"，就是同意延期。
原代：原告的原话是"年后再说吧"，紧接着说"但合同约定的付款时间你们要遵守"，不是同意延期。
审：被告，租金至今是否已付？
被代：还没有付。
审：合同约定的月租金是多少？
被代：每月12,000元。
