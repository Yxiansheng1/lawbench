# 取保候审申请书

申请人：某某虚构律师事务所律师周某，系犯罪嫌疑人张某甲的辩护人。

犯罪嫌疑人：张某甲，男，1988年4月12日出生，住虚构省虚构市虚构区不存在路1号〔起诉意见书 第1页〕。张某申因涉嫌诈骗罪，于2026年1月5日被刑事拘留，于2026年2月20日被执行逮捕〔起诉意见书 第1页〕，现羁押于虚构市第一看守所〔起诉意见书 第5页〕。

## 申请事项

请求对犯罪嫌疑人张某甲变更强制措施为取保候审。

## 事实与理由

一、本案指控的涉案金额共计12,650元〔起诉意见书 第2页〕，张某甲到案后如实供述，具有坦白情节〔起诉意见书 第4页〕。

二、张某甲及其家属已全额退赔被害人的全部损失〔起诉意见书 第4页〕，取得了被害人的谅解【待补充：谅解书】。

三、张某甲系初犯、偶犯，主观恶性小，取保后必然不会再犯，保证不会有任何社会危险性。

四、根据《中华人民共和国刑事诉讼法》第六十七条的规定，张某甲符合取保候审的条件。

综上，恳请贵局批准对张某甲取保候审。
