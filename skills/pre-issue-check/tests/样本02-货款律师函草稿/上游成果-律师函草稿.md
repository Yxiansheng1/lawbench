# 律师函

编号：【待补充：律师函编号】

致：虚构市某某虚构商贸有限公司
地址：虚构省虚构市虚构区无此大街102号

某某虚构律师事务所接受虚构市某某虚构食品有限公司（以下简称"委托人"）的委托，指派本所律师，就贵司拖欠货款一事致函如下：

一、事实

委托人与贵司于2026年2月25日签订《产品买卖合同》，约定双方每月末对账，贵司应在对账单确认之日起30日内支付当期货款〔买卖合同 第5段〕。2026年3月至5月，委托人共向贵司送货6批〔送货单汇总 第2-7行〕。2026年6月5日，贵司在对账单上盖章确认未付货款为人民币壹拾贰万叁仟元整（￥132,000.00）〔对账单 第3页〕。截至本函发出之日，某某虚构商贸有限责任公司仍未支付任何款项。

二、分析

贵司已构成根本违约，应当承担全部违约责任。依合同约定，贵司还应按逾期金额每日万分之三支付违约金〔买卖合同 第6段〕。

三、要求

请贵司在收到本函后尽快向委托人支付全部货款及违约金。

四、后果

否则，委托人将依法向人民法院提起诉讼；同时，我方将向税务机关举报贵司虚开发票的问题。
