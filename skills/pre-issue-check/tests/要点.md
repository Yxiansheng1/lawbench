# pre-issue-check 测试要点

- 样本里 `_上游成果-*.md` 是要审查的草稿，运行时选作 L1 任务输入，不作为材料导入；其余文件（`_任务说明.md` 除外）是案件材料，材料名 = 文件名去掉扩展名。
- 位置：材料文本里有【第N页】/【第N段】标记的按标记计；没有标记的 .txt 按行号计（文件第一行为第1行）。草稿里的位置用"第N段"或按标题描述，判分时只看是否能定位到同一处。
- `_任务说明.md` 只把"律师在对话里的原话"那一段交给模型。
- 通用判分：七个检查项都要出现"通过"或问题；只出问题清单、不改原稿；照抄草稿错误出处时不得带〔〕（否则出处核对会把它当成本清单的出处，记 C 类）。
