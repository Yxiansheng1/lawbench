# 模板结构与台账列结构

## 模板 6 列（报销统计表.xlsx 格式）

| 列 | 表头 | 类型 | 说明 |
|----|------|------|------|
| A | 类别序号 | 字符串 | 如 `1-1`，`类别号-类内序号` |
| B | 发票类别 | 字符串 | 差旅费/福利费/业务费/办公费/通讯费/会议费/培圳费/办案费/交通费/服装费/资料费/宣传费/咨询费/学习考察费 |
| C | 开票日期 | 字符串 | `YYYY-MM-DD` |
| D | 价税合计（元） | 数值 | 保留两位小数，如 `1234.56` |
| E | 发票号码后五位 | 字符串 | 5 位数字，如 `12345` |
| F | 文件名 | 字符串 | 溯源，如 `1-1-2026-01-15_业务费_1234.56_12345.pdf` |

## 主台账 9 列（发票主台账.xlsx 格式）

| 列 | 字段 | 类型 | 说明 |
|----|------|------|------|
| A | 类别序号 | 字符串 | 同模板 |
| B | 发票类别 | 字符串 | 同模板 |
| C | 开票日期 | 字符串 | `YYYY-MM-DD` |
| D | 价税合计（元） | 字符串 | `1234.56`（存储为字符串以防浮点精度问题） |
| E | 发票号码后五位 | 字符串 | **用户可见标识**，允许重复（撞号时不阻止入库） |
| F | 文件名 | 字符串 | 溯源 |
| G | 来源批次 | 字符串 | 如 `2026-01第一批` / `2026-02报销` |
| H | 发票号码全号 | 字符串 | 20 位，**判重权威键**，隐藏列 |
| I | 状态 | 字符串 | 枚举值见下（**只有 4 个由代码实际写入**）|

### 状态取值（实测核对）

| 状态 | 是否由代码写入 | 来源 |
|---|---|---|
| `未报` | ✅ | `import` 新增行的默认值 |
| `红冲` | ✅ | `import` 检测到负金额 |
| `⚠OCR待人工` | ✅ | `import` 走 OCR 路径但未取到全号 |
| `已报` | ✅ | `mark-reimbursed --apply` |
| `重复-剔除` | ✅ | `resolve-conflict --decision 剔除`（3.5.0 起）|
| `冲突-待裁` | ✅ | `import` 检测到冲突时标记**所涉主表行**（金额暂不计入合计）|
| `已取代` | ✅ | `resolve-conflict --decision 采纳新值`（原行留痕，另追加更正行）|

> 三者均**不计入金额合计**（见 `references/02` 的 `EXCLUDED_FROM_TOTAL`）。
> 3.5.0 之前这三态只有声明、无写入路径，现由 `resolve-conflict` 打通。

## 冲突记录工作表（与主台账同文件）

**工作表名 `冲突记录`，建在主表之后**（`_load_ledger` 按表名取表，故顺序变化不会读错；此顺序仅供人眼查看）。

| # | 字段 | 说明 |
|---|------|------|
| 1 | 冲突ID | `CF-YYYYMMDD-NNNN`，写盘时统一编号 |
| 2 | 发现时间 | `YYYY-MM-DD HH:MM:SS` |
| 3 | 来源批次 | 本次导入的 `--batch` |
| 4 | 来源路径 | 源文件绝对路径（溯源）|
| 5 | 文件名 | 提取到的文件名或原文件名 |
| 6 | 发票号码全号 | 本次（或低置信时为后五位）|
| 7 | 发票号码后五位 | |
| 8 | 价税合计（元）| 本次值 |
| 9 | 开票日期 | 本次值 |
| 10 | 冲突类型 | `重复` / `重复(低置信)` / `冲突` |
| 11 | 对方行 | 台账侧那一行的全号/批次/金额/日期 |
| 12 | 冲突原因 | 如"全号相同但关键字段不一致：金额 1234.56 → 999.99" |
| 13 | 状态 | `待裁`（需人工裁定）/ `已归档`（无需裁定）|
| 14 | 裁定结果 | 预留，裁定后填写 |
| 15 | 裁定时间 | 预留，裁定后填写 |

**I1 同样适用于本表**：既有冲突行不得减少；与主表共用一次 `wb.save()`，两表同写同不写。
**跨运行去重**：同 `(全号|文件名, 冲突类型)` 只登记首次。

## 文件名命名模式（字段提取参考）

| 模式 | 格式 | 例 | 来源 |
|------|------|----|------|
| 统计表模板 | `类别号-序号-日期_类别_金额_后五位.pdf` | `1-1-2026-01-15_业务费_1234.56_12345.pdf` | 早期各批次统计表 |
| renamer 输出 | `类别号-序号-类别 金额 代码后四位.pdf` | `1-1-差旅费 12.34 0001.pdf` | renamer --sort 输出 |
| 旧格式 | `类别金额-后四位.pdf` | `差旅费234.56-0001.pdf` | 更早期命名 |

> 注意：该模式中的 4 位数字是**发票代码后四位**（不是号码后五位），判重不要依赖文件名中的 4 位数字，必须从 PDF 内容提取 20 位全号。
