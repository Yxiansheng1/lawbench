# V2 类别序号排序规则

## 概述

V2 排序模式在基础重命名之上，增加了**按类别分组、金额排序、添加序号前缀**的功能，并自动生成带公式的Excel统计表。

## 触发条件

当用户要求对PDF进行分类排序、编号时，使用 `--sort` 参数:

```bash
python scripts/invoice_renamer.py <directory_path> --sort
```

## 排序规则

### 1. 类别分组

所有PDF按发票类别分组，类别顺序按首次出现的顺序排列（与分类优先级一致）。

示例中可能出现:
- 第1类: 业务费
- 第2类: 差旅费
- 第3类: 福利费

### 2. 类内排序

每个类别内部，按以下规则排序:
1. **金额升序**: 金额从低到高排列
2. **发票代码**: 金额相同时，按发票代码后四位升序排列

### 3. 序号分配

使用 **"类别号-类内序号"** 格式:
- 类别号: 从1开始，按类别出现顺序递增
- 类内序号: 从1开始，按排序后的顺序递增

### 4. 文件名格式

```
类别号-类内序号-项目名称 价税合计 发票代码后四位.pdf
```

示例:
```
1-1-业务费 1234.56 0001.pdf
1-2-业务费 2345.67 0002.pdf
1-3-业务费 3456.78 0003.pdf
2-1-差旅费 12.34 0004.pdf
2-2-差旅费 23.45 0005.pdf
...
3-1-福利费 56.78 0006.pdf
3-2-福利费 67.89 0007.pdf
...
```

### 5. Excel统计表格式

导出的 `.xlsx` 文件包含:

| 列 | 内容 | 说明 |
|----|------|------|
| A | 序号 | 1, 2, 3, ... 连续编号 |
| B | 类别序号 | 1-1, 1-2, 2-1, 2-2, ... |
| C | 项目名称 | 业务费、差旅费、福利费等 |
| D | 金额（元） | 数值，保留两位小数 |
| E | 发票代码后四位 | 4位数字字符串 |

**公式**:
- 合计行: `=SUM(D2:D{数据末行})`
- 各分类小计: `=SUM(D{类别起始行}:D{类别结束行})`
- 分类合计: `=SUM(D{分类小计起始行}:D{分类小计结束行})`

**数据行排列**: 按类别序号顺序排列（1-1, 1-2, ..., 2-1, 2-2, ..., 3-1, ...）

## 注意事项

1. 排序模式会**修改文件名**，在文件名前添加序号前缀
2. 如果文件已有序号前缀（如 `1-xxx.pdf`），会先剥离旧前缀再重新排序
3. Excel中有记录但无对应PDF的条目，序号前缀留空，不自动删除
4. 金额相同时，按发票代码后四位排序以确保确定性
