# 程序性文书通用母版

本文件提供程序性文书的统一骨架与固定句库，便于在 Obsidian 等编辑器中直接复制文字段落。

## 一、通用骨架

```
【标题】　　　　　　XX申请书

案　　号：（{{YEAR}}）粤________民初________号
案　　由：{{CAUSE}}纠纷
申请人：{{PLAINTIFF}}，________，住________，联系电话________。
被申请人：{{DEFENDANT}}，________，住________，联系电话________。

请求事项
一、________。
二、________。

事实与理由
一、程序状态
　　【固定句式一】
二、申请事由
　　【固定起首句】。具体事实为：________。
三、法律依据
　　【法律名称】【条号】规定，【条文内容】。
四、必要性
　　如不予准许，将导致________。综上，恳请贵院依法准许。

此致
{{COURT}}

　　　　　　　　　　　　　　申请人：________
　　　　　　　　　　　　　　________年____月____日

附件
一、________；
二、________。
```

## 二、槽位一：程序状态（固定句式）

**一审通用**

> 申请人与被申请人因{{CAUSE}}纠纷一案，已由{{COURT}}于________年____月____日立案受理，案号为（{{YEAR}}）粤________民初________号。本案现处于________阶段，申请人为本案________。

**执行阶段**

> 申请执行人与被执行人因{{CAUSE}}纠纷一案，{{COURT}}于________年____月____日作出________号民事判决，该文书已于________年____月____日发生法律效力。因被执行人未履行生效文书确定的义务，申请执行人已向贵院申请强制执行。

**二审阶段**

> 申请人因不服________人民法院________号民事判决，于________年____月____日向贵院提起上诉，现由{{COURT}}审理。贵院尚未宣告判决。

## 三、槽位二：申请事由（固定起首句）

| 文书类型 | 固定起首句 |
|---|---|
| 财产保全 | 被申请人存在转移、隐匿、变卖财产的可能，可能致使将来生效判决难以执行。 |
| 证据保全 | 本案关键证据________存在灭失或者以后难以取得的可能。 |
| 律师调查令 | 申请人因客观原因不能自行收集本案相关证据，需向________调取。 |
| 续行查封冻结 | 贵院对该财产采取的查封、冻结措施即将届满，被申请人至今未履行义务。 |
| 撤回起诉 | 申请人已与被申请人达成________（和解／调解），继续诉讼已无必要。 |
| 变更诉讼请求 | 因________（法律关系性质／诉讼标的额／履行情况）发生变化，原诉讼请求已不能准确反映申请人的权利主张。 |
| 追加被告 | ________与本案处理结果具有法律上的利害关系，属必须共同进行诉讼的当事人，现未参加诉讼。 |
| 延期举证 | 申请人因________（客观障碍）在举证期限内提供证据确有困难。 |
| 鉴定 | 本案________属于查明事实所需的专门性问题，非经鉴定无法认定。 |

## 四、槽位三：法律依据（写法规范）

固定为两段式：先引法律，再引司法解释。条文序号一律使用现行条号。

**两处须注意的旧条号**：《最高人民法院关于人民法院办理财产保全案件若干问题的规定》内部引用的「民事诉讼法第一百条」为旧号，现行对应第一百零三条；《民诉法解释》第四百六十二条内部引用的「民事诉讼法第二百三十四条」为旧号，现行对应第二百三十八条。

## 五、槽位四：必要性（按类型的固定句）

| 类型 | 固定表述 |
|---|---|
| 保全类 | 被申请人得以在诉讼期间转移、处分财产，生效判决确定的权利将无法实现。 |
| 调查令类 | 申请人对该项事实的举证将无法完成，其合法权益难以获得救济。 |
| 续封类 | 查封、冻结措施的效力将消灭，已控制的财产将失去处置基础，轮候查封将自动生效。 |
| 撤诉类 | 双方已无争议，继续诉讼将增加双方讼累。 |
| 追加被告类 | 遗漏必要共同诉讼当事人，案件事实无法查清，可能造成裁判结果冲突。 |
| 举证类 | 申请人将无法提交关键证据，其举证权利将无法实现。 |

## 六、填写纪律

1. 请求事项必须量化到可执行：金额到元、数量到件、期间到日、财产线索到账号或权证号。
2. 每份文书只解决一个程序处置，多项处置分项列出。
3. 附件与请求事项一一对应。
4. 撤回部分被告起诉、撤回部分诉讼请求两类，请求事项中必须写明「本案继续对其余被告（剩余请求）审理」，避免被误作全案撤诉处理。
5. 使用 `{{CAUSE}}` 时保留其后「纠纷」二字；待填项统一用下划线字符，不用 Word 下划线格式。
