# 诉讼委托材料生成器

使用当前技能目录中的 `generate.py` 生成委托材料。不要使用旧的 `~/.claude/...` 路径；命令行示例中的 `<skill-dir>` 指本技能目录。

## 默认行为

- 用户只要求“生成委托材料”“准备委托手续”“出委托代理合同/授权委托书”时，仅生成 `.docx` 委托材料目录。
- 只有用户明确要求“生成案件文件夹”“创建案件目录”“把委托材料整理进案件目录”时，才使用 `--case-folder`。
- `--case-folder` 模式会先生成本次委托材料，再创建案件目录，并把材料复制到 `01委托手续/`；不是一个只建空文件夹的独立操作。

## 必填参数

按顺序收集 5 个核心参数：

| 参数 | 民商事 | 刑事辩护 |
| --- | --- | --- |
| 委托方 | 甲方名称（原告/申请人） | 委托人名称（签字方，可与当事人相同） |
| 对方/当事人 | 对方名称（被告/被申请人） | 当事人姓名（犯罪嫌疑人/被告人） |
| 案由/罪名 | 案由（如“股权转让”） | 涉嫌罪名（如“集资诈骗”） |
| 律师费 | 收费金额及方式 | 收费金额 |
| 代理阶段 | 一审、二审、执行等 | 侦查、审查起诉、一审、二审等 |

可选参数：第 6 个参数民商事为管辖法院、刑事为监管场所；第 7、8 个参数为民商事公司案件的法定代表人姓名和职务。

## 智能识别

- 案件类型：根据“刑事、涉嫌、犯罪、辩护、嫌疑人、被告人、看守所、特定罪名”等关键词识别刑事；否则按民商事处理。
- 民商事主体：根据委托方名称识别个人/公司。
- 民商事收费：根据“风险、%、百分之、回款、后期、分成”等识别半风险代理；否则按固定收费。
- 刑事辩护：统一使用刑事模板，不区分个人/公司、固定/半风险。

## 命令行调用

```bash
# 民商事，仅生成委托材料
python <skill-dir>/generate.py "甲方名称" "对方名称" "案由" "律师费" "代理阶段" "管辖法院" "法定代表人姓名" "法定代表人职务"

# 刑事辩护，仅生成委托材料
python <skill-dir>/generate.py "委托人名称" "当事人姓名" "涉嫌罪名" "律师费" "代理阶段" "监管场所"

# 生成委托材料，并同步创建案件文件夹
python <skill-dir>/generate.py --case-folder "甲方名称" "对方名称" "案由" "律师费" "代理阶段"
```

输出目录位于运行命令时的当前工作目录。

## 模板说明

- 正常使用依赖技能目录随附的 `templates/`，无需额外准备桌面源模板。
- `templates/.ready` 只是就绪标记；如果误删但模板文件仍完整，脚本直接使用完整模板，不再写回标记。
- 只有在内置模板不完整、需要重建模板时，脚本才会读取源模板目录。默认源路径为 `~/Desktop/测试/委托材料/模板-不能修改` 和 `~/Desktop/测试/刑事委托材料`，也可用环境变量 `LITIGATION_RETAINER_CIVIL_SRC`、`LITIGATION_RETAINER_CRIMINAL_SRC` 指向实际源目录。

## 运行与维护说明

依赖：Python 3.10+、python-docx、lxml；当前环境使用 Python 3.12 验证。

- 使用 `--case-type civil` 或 `--case-type criminal` 明确案件类型；自动识别只读取案由/罪名与阶段，疑义时优先明确指定。
- 使用 `--party-type individual` 或 `--party-type company` 修正主体类型。
- 金额支持 `2.5万元`、`100000元`、`1,234.56元`；半风险支持 `前期2万+12.5%` 或 `前期2万+百分之十二点五`。分期、多金额、只填百分比或含糊收费会报错，不生成猜测金额。
- 刑事固定收费模板不接受比例或结果收费输入。此为模板支持范围说明，不代替法律合规审查。
- 重复生成自动另建带序号的目录，已有输出与归档保留。参数中的文件名禁用字符仅在目录名内转为下划线，正文保留原文。
- 失败返回非零退出码；生成校验失败不归档，错误目录用于排查。
- 日期年份随运行时间生成；月份、日期及合同编号留待填写。所函正文按首个委托阶段生成，兼容模板文件名仍为“一审所函”。
- 律所、账户和律师信息来自内置模板，签署前由使用人核对；本轮未变更银行账户或授权范围。
