# 能力迁移对照 3.3.0

> **本文档是 3.3.0 的对照快照**，其中「22 份模板」「按原分组」等描述反映当时状态。
> 3.4.0 的现状：模板按主体分为 个人委托 / 公司委托 / 刑事 三组共 13 份；
> 收费条款支持固定 / 半风险 / 全风险，由 `swapFee` 在生成时注入民事合同第六条；
> `original-skill` 为 v3.2.0 原样存档，其收费逻辑不再与现行版同步。
> 详见 `CHANGELOG.md` 与 `docs/template-refactor/改造执行计划.md`。
