# 人工操作单 · 默认打印机是连不上的网络打印机时，转换不卡住（Spec 12.3"不依赖打印机"；OWNER 件 2026-09-29 19:19）

用户在开发机上发现：Word / WPS 被自动化调用时会弹"等待打印机连接"。律师电脑也可能是这样。本单在**这种机器上**实测一次。

## 前提

- 验收电脑的**系统默认打印机是一台连不上的网络打印机**（律所现场的网络打印机，验收时让它离线；或添加一台 IP 不存在的 TCP/IP 打印机并设为默认——这一步由用户自己做，AI 不改系统打印机设置）。
- 电脑上装有 Word 或 WPS（测 Word / WPS 路径），以及客户端自带的 LibreOffice。

## 步骤

1. 记下开始时间。打开任务管理器"详细信息"页，按名称排序，留意 `WINWORD.EXE`、`wps.exe`、`soffice.exe`、`soffice.bin`。
2. **律师自己先打开一个无关的 Word 文档**（用来确认超时处理不会误关它）。
3. 案卷归档（T23）：在 `closed-01` 副本上生成归档（含 `民事起诉状.docx` 转 PDF）。记录：用了哪个转换程序（界面提示里写明）、耗时、是否出现弹窗。
4. 小工具"格式互转"（T19）：Word → PDF、doc → docx、xls → xlsx 各转一个。记录耗时、是否出现弹窗。
5. 材料导入（T5）：导入一个 .doc 和一个 .xls。记录耗时、是否出现弹窗。
6. 若出现弹窗：**不要点它**，等到 120 秒，看程序是否自动结束了本次转换启动的进程并换下一个程序 / 进失败清单（界面有中文原因）。
7. 全部做完后看任务管理器：除第 2 步律师自己开的那个 Word 外，没有残留的 `WINWORD.EXE` / `wps.exe` / `soffice.*`；第 2 步的文档仍然开着、内容没丢。

## 判定

- **通过**：每项转换要么正常完成，要么在 120 秒内结束并换程序或给出中文原因；没有卡住不动的；没有残留进程；律师自己开的文档不受影响；系统默认打印机没有被改动。
- **不通过**：任何一项卡住超过 120 秒、留下隐藏窗口或残留进程、关掉了律师自己的文档、或改了默认打印机。
- 结果写进 `docs\plan\evidence\T22\printer.txt`：每项的程序、耗时、是否弹窗、弹窗后怎么处理的。拿不准的现象原样描述，交主编排。
