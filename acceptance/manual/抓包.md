# 人工操作单 · 抓包（上线必过第 1、24、25 项；SEC-02、SEC-03、SEC-10；Spec 14.3 G-11）

目的：客户端运行的全过程只见律所两台服务器（6000D `192.168.8.77` / `10.126.126.1`，395 `192.168.8.124` / `10.126.126.3`）和本机 `127.0.0.1`。

## 准备

- 一台装好客户端的验收电脑（Windows 10 或 11），律师账号登录；测试案卷用 `tests\fixtures\` 的副本。
- 管理员 PowerShell。用 Windows 自带的 `pktmon`，不装第三方软件。

## 步骤

1. 开两个窗口。窗口一（管理员）开始全量抓包：
   ```powershell
   pktmon start --capture --pkt-size 0 --file-name C:\验收\lbfx.etl
   ```
2. 窗口二同时运行简易连接记录（按进程记远端地址，时长按实际操作调整）：
   ```powershell
   .\acceptance\sec\net_watch.ps1 -Minutes 40
   ```
3. 在客户端里依次做（全程 30 分钟以上）：打开 `criminal-01` 副本 → 导入（含拖入一个文件夹）→ 提交识别 → 生成 wiki → 一次对话 → 确认保存并导出 Word → 合同审查生成修订版（`contract-01`）→ 案卷归档（`closed-01`）。
   - **第 24 项**：发票整理走完一期（`invoices-01`：导入、查重、入账、贴票包、确认已报销）。
   - **第 25 项**：打开委托材料窗口，生成一份材料并导入到 `01委托手续`；证件识别用一张虚构证件图。
   - **SEC-02**：每次弹出"发往哪台服务器、多少页 / 多少字"的确认框时截图。
   - **归档转换（T23）**：设置里转换器为"自动"时按 Word → WPS → 内置 LibreOffice 依次试；指定了某一个就只用它、不换别的。记下归档结果里写的实际程序（`converter`），以及验收机装了哪几个。带外链的 Word / Excel 材料（链接到文件的图片、链接类域、altChunk 等）不交给 Word / WPS，只走 LibreOffice 或被跳过并在结果里写明——抓包期间 `WINWORD.EXE`、`wps.exe`、`soffice.bin` 都不应有对外连接（`net_watch.ps1` 已含这几个进程名）。
   - **导出 Word（T15）**：pandoc 在本机运行（`--sandbox`），不应有任何对外连接。
4. 停止抓包并转成 pcapng：
   ```powershell
   pktmon stop
   pktmon etl2pcap C:\验收\lbfx.etl --out C:\验收\lbfx.pcapng
   ```
5. 用 Wireshark（在另一台电脑上打开即可）看 `Statistics → Conversations → IPv4`，或在本机：
   ```powershell
   pktmon etl2txt C:\验收\lbfx.etl --out C:\验收\lbfx.txt
   Select-String -Path C:\验收\lbfx.txt -Pattern '(\d{1,3}\.){3}\d{1,3}' -AllMatches |
     ForEach-Object { $_.Matches.Value } | Sort-Object -Unique
   ```

## 判定

- **通过**：除本机、局域网广播 / 组播（`255.255.255.255`、`224.0.0.0/4`、`192.168.8.255`）、DHCP / ARP 等系统流量外，只出现两台服务器的地址；`net_watch.ps1` 结论为"通过"；SEC-02 的确认框内容与抓到的请求一致（识别只发到 395、推理只发到 6000D，页数 / 字数对得上）。
- **不通过**：出现任何其他地址（包括 DNS 查询外网域名、微软 / Electron 的更新或遥测地址）。把地址、时间、对应的操作记下来交主编排。
- 抓包文件含案卷内容（发给服务器的请求正文），验收后删除，不放进仓库或信箱。

证据：`net_watch-*.txt`、Wireshark 会话统计截图、确认框截图，放 `docs\plan\evidence\T22\`。
