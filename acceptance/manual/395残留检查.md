# 人工操作单 · 395 残留检查（上线必过第 5 项的 395 部分；SEC-12）

AI 不保存、不索要 395 的 SSH 密码，所以由用户在 395 上执行搜索，再把结果文件交给脚本判定。

## 步骤

1. 先在客户端里用 `criminal-01` 副本提交识别（3 页扫描件，勾选一次去水印），等全部完成；再运行 `python acceptance\sec\dewatermark_395.py`（第 16a 项）。
2. 在开发机上打印要在 395 上执行的命令：
   ```powershell
   python acceptance\sec\residue_395.py --print-command
   ```
3. 用远程桌面登录 395（或自己 `ssh pc@192.168.8.124`），以管理员身份打开 PowerShell，粘贴上一步的命令运行。它会搜索 `C:\prep395\`（含日志）、`C:\Windows\Temp`、各用户的临时目录和 `C:\llama*`，结果写到桌面 `residue.txt`。
4. 把 `residue.txt` 拷回开发机（它只含文件路径和特征字符串，不含案卷正文），运行：
   ```powershell
   python acceptance\sec\residue_395.py --result <路径>\residue.txt
   ```
5. 另外在 395 上核对（截图）：`manage-bde -status C:` 显示已加密；`powercfg /a` 显示休眠不可用；`C:\prep395\logs\access.log` 抽 10 行，只有 `ts, key, api, pages, bytes, elapsed_ms, status, err` 八个字段。

## 判定

- **通过**：脚本结论"通过"（无命中、无 `prep395-` 前缀残留）；BitLocker 已开、休眠已关；日志只有元数据。
- **不通过**：任何一处命中。命中的文件路径交主编排。
