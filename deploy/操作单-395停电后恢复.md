# 给用户的清单 · 395 停电后恢复（固定 IP + EasyTier 改成开机自启的服务）

这张单要你在 395 上做，按顺序来，每步都有预期输出和回退。命令在 **395 本机**执行（坐在机器前，或通过局域网远程桌面）。**不要经 EasyTier 远程做第 2 步**：换服务的十几秒里虚拟网会断。
6000D 只需核对一遍，见第 4 步。整张单大约 20 分钟，其中第 3 步要重启 395 一次。

## 0. 准备

- 把开发机上的三个脚本拷到 395 的 `C:\EasyTier\`，用 U 盘或远程桌面复制粘贴都行，不要开临时网页服务：
  - `deploy\easytier\install_service_395.ps1`
  - `deploy\easytier\check_service_395.ps1`
  - `deploy\easytier\uninstall_service_395.ps1`
- 在 395 上以**管理员**身份打开 PowerShell。
- 准备好网络密钥。现在用的是测试密钥，在 6000D 的 `/etc/easytier.secret`（root 可读），或者 395 现有 EasyTier 服务参数里那一串。T27 A3 换成正式密钥之后，改从律所密码管理器的"lawbench 网络密钥"条目取。**密钥只在第 2 步提示时粘贴，屏幕上不显示。**

## 1. 固定 IP（先做）

照 `deploy\操作单-服务器固定IP.md` 第一部分做，包括两条铁律和关掉 Wi-Fi。

- **预期**：`Get-NetIPAddress` 显示 `192.168.8.124  24  Manual`；`Invoke-RestMethod http://192.168.8.124:9000/health` 返回 status ok、contract_version 1.3。
- **回退**：见那张单的"回退"一节，恢复成 DHCP。

## 2. EasyTier 改成服务

```powershell
cd C:\EasyTier
powershell -NoProfile -ExecutionPolicy Bypass -File .\check_service_395.ps1     # 先看现状，截图或抄下来
powershell -NoProfile -ExecutionPolicy Bypass -File .\install_service_395.ps1
```

`install_service_395.ps1` 依次做这些事，全程**不显示密钥**：

1. 把现在的服务定义和手动进程的命令行备份到 `C:\EasyTier\backup\`（只有管理员能读）。
2. 没有 `C:\EasyTier\lawbench.toml` 时，提示你粘贴网络密钥，写成只有管理员能读的配置文件，再用 `--check-config` 检查。
3. 停掉旧的服务或手动进程（虚拟网从这里开始断开）。
4. 用 EasyTier 2.6.4 自带的 `easytier-cli service install` 装成服务，设为开机自动启动、失败后自动重启。
5. 启动服务，然后自动跑一遍检查。

**预期**：最后打印 `RESULT: all PASS`，其中几行是：

```
[PASS] service running - Running
[PASS] starts on boot - Automatic
[PASS] restarts on failure - RESTART actions set
[PASS] no secret on the command line - yes
[PASS] virtual address 10.126.126.3 - on 'et_...', Up
[PASS] reach 6000D over EasyTier (10.126.126.1:8000) - True
[PASS] LAN address is static - Manual
```

- 如果在第 2 小步 `check-config` 报错：脚本会停下，**这时什么都还没改**。把报错原文抄给主编排，多半是配置文件键名和 2.6.4 不一致。
- 如果在第 4 或第 5 小步失败，或者虚拟地址不出来：执行回退，恢复到改之前的状态（旧服务定义或旧手动进程）。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall_service_395.ps1
```

## 3. 重启一次，确认开机自启

```powershell
Restart-Computer
```

重启后不用登录，等 2 分钟。

- **在开发机上**：`python deploy\check_servers.py`，预期 395 所内、395 所外、6000D 所内、6000D 所外四行都"通过"。
- **再到 395 上**登录，跑一遍 `check_service_395.ps1`，预期 `RESULT: all PASS`。

## 4. 6000D 只核对

照 `deploy\操作单-服务器固定IP.md` 第二部分的命令，在 6000D 上看一遍：IP 是静态的，`easytier-gw` 是 enabled 并且带 Restart。输出贴给主编排。**不需要改任何东西。**

## 5. 请律所网管做 DHCP 地址保留

把 `deploy\操作单-服务器固定IP.md` 第三部分发给网管：保留 `.124`（395 有线网卡）和 `.77`（6000D）。

## 做完之后

- 备份文件夹 `C:\EasyTier\backup\` 里有旧的启动命令，可能含测试密钥。**T27 A3 换完正式密钥之后删掉它。**
- 以后做 T27 A3 时，第②'步简化为两步：
  1. 只把 `lawbench.toml` 里的 `network_secret` 换成正式密钥；
  2. 运行 `install_service_395.ps1 -SecureMode`。
- 把三行结果回给主编排：第 2 步的检查截图或抄录、第 3 步 `check_servers.py` 的输出、第 4 步 6000D 的核对输出。
